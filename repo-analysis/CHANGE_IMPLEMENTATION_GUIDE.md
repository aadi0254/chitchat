# ChitChat | Future Change Implementation Guide

## 1. Repository Conventions & Standards

When making modifications to the ChitChat repository, adhere to the following established rules:

1. **Language & Types**: All new code must be written in strict TypeScript. Avoid `any`; declare explicit interfaces for all data structures, props, and event payloads.
2. **Path Aliasing**: Always use the `@/*` alias (e.g., `@/lib/utils`, `@/components/chat/sidebar`) rather than relative traversal (`../../lib/utils`).
3. **Styling Paradigm**:
   - Use Tailwind utility classes combined with `cn()` from `@/lib/utils`.
   - Use HSL theme tokens (`bg-primary`, `bg-secondary`, `bg-accent`, `bg-background`).
   - For blurred semi-transparent panels, use the existing glass utilities (`glass`, `glass-card`).
4. **Icons**: Use `lucide-react`. Maintain consistent icon sizing (`size={16}` for inline labels, `size={20}` for buttons/headers, `size={32}` or `size={48}` for hero cards).
5. **Client Boundary**: Any component interacting with browser APIs (`BroadcastChannel`, `sessionStorage`, `navigator.clipboard`, `window`) must include `"use client";` at the top of the file.

### Recipe B: Fixing the Ghost Presence Leak on Tab Close
- **Objective**: Ensure that closing a tab immediately broadcasts `LEAVE` to other participants.
- **Files to Modify**: [`app/page.tsx`](file:///c:/Users/karsh/Desktop/websites-source-codes/chit-chat/chitchat/app/page.tsx)
- **Step 1**: Locate the main `useEffect` or create a new dedicated effect in `app/page.tsx`.
- **Step 2**: Register a `beforeunload` event listener:
  ```typescript
  useEffect(() => {
    const handleBeforeUnload = () => {
      if (view === "chat" && socket) {
        socket.leave();
      }
    };
    window.addEventListener("beforeunload", handleBeforeUnload);
    return () => {
      window.removeEventListener("beforeunload", handleBeforeUnload);
    };
  }, [view]);
  ```
- **Step 3**: Test by opening two tabs in the same room. Close one tab and verify that the remaining tab immediately sees the user disappear and displays a system message `"[User] left the chat"`.

## 5. Pre-Commit Verification Checklist

Before staging and committing any future code modifications, follow this rigorous verification checklist:

1. [ ] **Lint Clean**: Run `npm run lint` and verify zero ESLint errors or warnings.
2. [ ] **TypeScript Check**: Run `npx tsc --noEmit` to confirm zero type errors.
3. [ ] **Build Validation**: Run `npm run build` to verify webpack and font compiler succeed.
4. [ ] **Multi-Tab Sync Verification**: Open two distinct tabs in `http://localhost:3000`, join room `TEST99`, send messages back and forth, and confirm instant delivery.
5. [ ] **Clean Git Status**: Run `git status` to ensure no accidental build artifacts (like `node_modules` or `.next`) are staged.
6. [ ] **Preserve Unrelated Code**: Do not delete comments or refactor existing working logic unless directly part of the requested change.
